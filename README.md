- **Typography**: Plus Jakarta Sans (body & headings) + JetBrains Mono (technical badges & terminal).
- **Micro-Interactions**: Ambient constellation particle background, dynamic typing hero text, 3D hover effects, scroll reveal animations, and interactive simulator.

## 💻 How to View Locally

Simply double-click `index.html` to open in any web browser, or serve using Python:

```bash
# In this directory:
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your browser.
